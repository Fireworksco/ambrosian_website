# Ambrosian Events & Management Website

A professional static portfolio website for Ambrosian Events & Management, showcasing comprehensive event services in London.

## 🌟 Features

- **Modern Dark Theme**: Custom dark color scheme (#0b1c35) with gold accents (#fbcc7b)
- **Fully Responsive**: Mobile-first design that works on all devices
- **Service Pages**: Dedicated pages for 6 main services
- **SEO Optimized**: Meta titles and descriptions for all pages
- **Fast Performance**: Built with Next.js for optimal speed
- **Static Export**: Can be deployed to any static hosting platform

## 🛠️ Tech Stack

- **Next.js 14**: React framework with App Router
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first CSS framework
- **Static Export**: Ready for deployment

## 📄 Pages

- **Home**: Overview of services and company introduction
- **Contact**: Contact form and business information
- **Service Pages**:
  - Catering & Wedding Cuisine
  - Professional Event Staffing
  - Decoration & Event Styling
  - SIA Security Services
  - Marketing & Event Management
  - Photography & Videography

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
```

This will create a static export in the `out` directory.

### Start Production Server

```bash
npm start
```
